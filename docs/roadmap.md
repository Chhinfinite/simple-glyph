# Roadmap

## 设计原则

1. **可检查**：每个阶段都有可视化 overlay，不靠“看起来差不多”。
2. **半自动优先**：宁可让用户点 3 个点，也不要输出不可控的自动分割。
3. **中心线优先**：先保证笔顺和拓扑，再谈笔宽/纹理。
4. **零运行时网络**：库本身不联网；标准数据由用户显式提供或缓存。

## 非目标

- 替代专业字库设计；
- 把动画写进另一款手写 App（需要系统级注入，和本项目不是同一层）。
